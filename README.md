# Portfolio

> ** Software Developer · QA Engineer · SDET **

## Overview
I'm Satyam, a **Software developer, QA engineer and, Software Development Engineer in Test (SDET)** based in Mumbai. It brings my skills, projects, learning journey and resume together in one place, and it is built and tested the way a professional team would build a product.

## Audience
- **Recruiters:** they skim many profiles. In 30 seconds they want to know my target role, my core skills, and how to get my resume.
- **Hiring managers and engineers:** they want evidence. They look for real projects, readable code on GitHub, and signs that I test my work.

## Goals
1. A recruiter can find my resume and contact details within 10 seconds of opening the site.
2. A hiring manager can see my skills and their depth (comfortable, working knowledge, learning) without reading a long page.
3. An engineer can open a project and its code in one click, and see how the portfolio itself is tested.

## Sections
- **Hero:** name, target roles and links to the resume and projects. It tells the visitor who I am at once.
- **Skills:** an interactive skill tree with levels. It shows depth honestly.
- **Projects:** cards with tech tags, a filter, and links to code and demos. This is the main proof of ability.
- **Learning and teaching:** what I'm learning now, plus my YouTube channel. It shows growth and communication.
- **Contact:** email, LinkedIn and GitHub, and a resume download.


## Non-goals
- No blog or CMS.
- No user accounts or backend.
- Not a template or product for other people to reuse.
- No heavy animations that slow the page down.

## Done criteria
1. The site is live at a public URL and redeploys automatically when `main` is updated.
2. Mobile Lighthouse scores are 90 or above for performance and 95 or above for accessibility.
3. The automated test suite (unit, end-to-end and accessibility) passes in CI before any merge.
4. Every section works on a phone-sized screen and a desktop screen, in both light and dark mode.
5. The resume and each project's code can be reached in one click from the home page.
